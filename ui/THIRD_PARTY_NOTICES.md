# 第三方素材与参考来源

## MiniMax H3 示例视频

以下文件复制自工作区中 MiniMax H3 仓库随附的 `assets/` 目录，用于演示播放器与工作流界面：

- `assets/i2va.mp4`
- `assets/t2va.mp4`
- `assets/ref2va.mp4`

上游项目：[MiniMax-AI/MiniMax-H3](https://github.com/MiniMax-AI/MiniMax-H3)。

这些视频不是本工作台生成的；其权利与适用条款归原权利人及上游项目。本 UI 项目不对第三方素材重新授予许可。

`docs/workbench.png` 为本工作台截图，其中包含上述示例视频的画面。

## 界面参考

交互方式参考 [ComfyUI 的界面概览](https://docs.comfy.org/interface/overview)。本项目没有包含 ComfyUI 源代码或模型权重。

MiniMax 与 ComfyUI 名称用于说明兼容目标和参考来源。本项目为独立 UI，不是上述项目的官方客户端。
